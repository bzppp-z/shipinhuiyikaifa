# 已知限制

以下内容按当前代码核对；历史思维导图里的分析可能已过时。

- `Server/include/packdef.h` 将 MySQL 账号和口令直接写在源码中。运行前需替换；公开仓库或线上服务应使用本地配置、环境变量或密钥管理系统。
- 服务端通过 `sprintf` 拼接 SQL 请求，字段内容来自客户端，需改为参数化查询并验证请求长度。
- 客户端使用 MD5 计算密码摘要，不等于可靠的密码存储或传输保护。生产系统应使用安全的密码哈希和 TLS。
- 两端独立维护结构体协议，未提供版本兼容与字段验证。接收路径应先验证包长、消息类型和消息长度。
- 房间和在线用户保存在内存中，进程重启后丢失。异常断线时清理房间成员与媒体 socket 绑定的完整性也需要加强。
- 摄像头对象在 Qt 主线程和视频 worker 间被打开、读取、释放；跨线程资源生命周期需要统一管理。
- 桌面采集发送原始屏幕尺寸的 JPEG 图片，媒体转发没有统一最大帧长和慢客户端背压。
- 客户端工程中的 OpenCV include 和链接库仍引用作者本机的 Windows 路径，克隆后需改成本机兼容的 OpenCV 4.2 MinGW 安装位置。仓库没有自动化端到端测试。

适合优先完善的方向：移除硬编码依赖和数据库口令、参数化数据库查询、验证网络消息边界、改进断线清理和媒体帧背压，并增加自动化协议与房间测试。
