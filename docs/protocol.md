# 协议说明

客户端和服务端分别维护一份消息结构定义：`WeChat/netapi/net/packdef.h` 与 `Server/include/packdef.h`。当前消息类型以 `10000` 为基数，覆盖账户注册和登录、房间创建和加入、成员离开、音频帧、视频帧及媒体连接注册。每个 TCP 消息前带有包长度，接收端按长度读取后，再根据消息类型查表分发。

登录成功后，客户端分别在音频和视频连接上发送连接注册消息。服务端据此建立用户 ID 到 socket 的映射，再依据媒体消息中的房间号转发帧。桌面截图复用视频帧结构和转发处理路径。

当前实现直接发送本机编译器生成的 C++ 结构体，依赖两端字段顺序、整数大小、对齐和字节序一致。协议没有版本协商，也没有统一 schema，不能视为通用跨平台格式。任何结构变化都必须同步修改两份定义，并确保接收端验证包类型和最小帧长度。生产版本应采用具有明确版本、字段宽度、字节序及最大消息长度的序列化格式。
